### 讨论要点

#### 议题一、二

- 回顾上周四项任务；请同学分享 W01 探索笔记，交流科学上网与服务器使用的实际问题。

#### 议题三

- 区分聊天机器人与 Agent：差别不在模型更聪明，而在于模型外面套的那层 Harness。
- 公式：Agent = 模型（大脑）+ Harness（手脚 + 循环 + 上下文/权限）。
- 一句话概括：模型负责想，Harness 负责做；换模型只是换大脑，手脚不变。

#### 议题四

- 梳理五种形态：IDE 集成（Qoder、Cursor）、终端 CLI（Claude Code、Codex CLI）、桌面办公（WorkBuddy）、网页云端（ChatGPT Agent 类）、技能插件（Skills）。
- 强调：很多 Agent 产品本质上只是一个 Harness。

#### 议题五

- Skill 是把"某类任务怎么做"打包成可复用包：说明 + 步骤 + 脚本/模板 + 检查清单。
- 类比"给新同事的 SOP 手册""游戏技能书"；作用是固化团队经验，结果更稳、减少重复解释。
- 推荐 `mattpocock/skills` 的 `teach` skill 与 `obra/superpowers`。
- 边界：Skill 不改变模型本身，只提供更专业的做事方法。

#### 议题六

- 现场演示 Qoder（IDE 集成）与 Claude Code + ccswitch（终端）；对比两种形态的使用场景。
- 环境建议：开发相关场景尽量放在服务器或虚拟机里，干净、不怕折腾坏本机。

#### 议题七

- 布置 W02 作业「AI + GitHub 闭环」：准备自己的东西 → 建个人仓库上传 → 装 `teach` skill 学 Linux 基础 → 向团队仓库提 PR。
- 规则不变：先问 AI → 动手去做 → 做成后留档。

### 结论

- Agent 与 Skill 的概念讲完，两种形态现场演示完成。
