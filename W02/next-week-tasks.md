### 新生

<!-- 统一流程，任务一致 -->

**规则不变**：先问 AI → 动手去做 → 做成后把收获留档。W01 探索笔记没交的同学，这次可以跟着再学，不急。

**作业目标**（具体操作可以交给 AI 来做，但整个流程自己要懂）：

1. **Agent**：知道它是什么——模型 + Harness，能自己拆步骤、调用工具、看结果；
2. **Skill**：知道它是什么、怎么装、怎么用，并亲手试用一个（`teach`）；
3. **Linux**：知道在服务器上跑通一个程序要做哪些事——装依赖、路径与权限、编译 / 解释执行、运行、排错；
4. **建库**：知道怎么在自己的 GitHub 上新建仓库并上传代码；
5. **做贡献**：知道怎么向别人的仓库提 PR（fork / 分支 / Pull Request），完整走通一次。

**本周作业：AI + GitHub 闭环**

- [ ] **1. 准备一个"自己的东西"**
  - 可以用 AI 做一个新的小东西（小网页 / 小游戏 / 命令行小工具 / 自动化脚本），也可以是自己以前的作业、项目、作品；题材不限。

- [ ] **2. 在个人 GitHub 建库并上传**
  - 新建一个仓库，把它传上去（让 AI 手把手教，网页版或本地 git 均可）。

- [ ] **3. 用 `teach` skill 学 Linux**
  - 给自己的 Agent 装上 `mattpocock/skills` 里的 `teach` skill，用它学一个 Linux 基础主题——建议就学「在 Linux 上跑通一个程序需要做哪些事」（装依赖、编译 / 解释执行、权限、路径、运行、排错）。

- [ ] **4. 向团队仓库提 PR**
  - 在 `W02/<你的缩写>/` 放一份说明文件（名字随意，按仓库规则用英文即可）；
  - 写清两件事：**这周做了什么**（东西是什么、仓库链接、AI 帮了什么忙）和**学到了什么**（用 `teach` 学到的要点、自己的体会，以及以后怎么维护更新自己的 GitHub 账号、怎么给别人的仓库做贡献）。

**成本提示**：想体验 API 路线的，可以先在 DeepSeek 少充一点感受一下；不充值也不影响完成作业（网页版 / Qoder / WorkBuddy 都可以）。

**提交**：截止下次组会前；PR 提交到团队仓库的 `W02/<你的缩写>/`。
