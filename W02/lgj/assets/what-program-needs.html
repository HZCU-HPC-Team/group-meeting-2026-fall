程序跑起来还缺什么

依赖三阶段 · 环境变量 · 权限数字 · 学习主渠道为对话实操

核心表：缺依赖的三个时刻

时刻缺什么报错特征
编译期头文件 .hfatal error: 'xxx.h' file not found
链接期函数实现undefined reference to 'xxx'
运行期动态库本体error while loading shared libraries

要点

  • otool -L(Mac) / ldd(Linux) 列依赖；.o 736 字节 → 可执行 33KB，差值 = 链接器从库搬来的代码。
  • 运行时找库由动态加载器执行；环境变量 DYLD_LIBRARY_PATH/LD_LIBRARY_PATH 是它的调节开关。
  • export PATH="$PWD:$PATH" 临时把当前目录加进命令搜索清单（仅当前终端有效）。
  • 权限数字：644=rw-r--r--，755=rwxr-xr-x；umask 022 决定新建文件默认 644。
