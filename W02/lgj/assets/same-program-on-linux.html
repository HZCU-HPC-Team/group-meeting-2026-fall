在真 Linux 上跑同一个程序

hzcu-hpct · Ubuntu 22.04 · gcc 12.3 · 学习主渠道为对话实操

同一份 hello.c，两个系统

代码不改一字，在 Mac（clang/arm64/Mach-O）和 Ubuntu（gcc 12.3/x86-64/ELF）都跑通——C 可移植，产物与环境不可移植。

实测输出判读

  • ELF 64-bit LSB pie executable, x86-64, dynamically linked, interpreter /lib64/ld-linux-x86-64.so.2 —— ELF 格式；PIE=位置无关+地址随机化；interpreter 是动态加载器。
  • ldd 三行：linux-vdso（内核映射的虚拟库，磁盘上不存在）、libc.so.6（glibc）、加载器本身。
  • 退出码：0 成功 · 126 命令在但不可执行 · 127 命令没找到。

两个「意外即教材」

  • sqrt 没炸：glibc 2.35 把数学函数并入 libc，-lm 在 Ubuntu 22.04 成历史遗留。版本决定行为。
  • boom 爆炸现场：warning: implicit declaration（编译期，C89 遗留：未声明函数默认按 int 处理）→ /usr/bin/ld: undefined reference（链接期）→ collect2: error: ld returned 1 exit status。一份输出里看清两个阶段。

装依赖动线

ldd ./程序 → 找到缺的库名 → dpkg -S /路径/库名 → 查到包名 → sudo apt install 包名

实测：dpkg -S /lib/x86_64-linux-gnu/libc.so.6 → libc6:amd64；apt-cache policy libc6 → Installed 2.35-0ubuntu3.15。
