## Status values

- **Not started** — assigned, not begun
- **In progress** — being worked on
- **Pending review** — submitted, awaiting feedback
- **Done** — accepted, no further changes needed

Once an item is done, move it from *In progress* to *Completed* and fill in the submission date and folder path.
