# Assignments · Fall 2026

One folder per topic + name, placed at `assignments/<topic>-<yourname>/`.

Assignments are usually assigned in a weekly meeting. The week they belong to is recorded in the
**Assigned in** column below, which points at the matching `instructor/Wxx/next-week-tasks.md`.

## Status values

- **Not started** — assigned, not begun
- **In progress** — being worked on
- **Pending review** — submitted, awaiting feedback
- **Done** — accepted, no further changes needed

Once an item is done, move it from *In progress* to *Completed* and fill in the submission date and folder path.

## Naming

Use a short, descriptive topic slug and your name as it appears in the team roster, all lowercase:

```
assignments/
├── benchmark-proposal-xunuo/
└── slides-review-zhangsan/
```

Pull requests from individual students are welcome for your own folder — it keeps the history
attributable and avoids merge conflicts in the shared list.
