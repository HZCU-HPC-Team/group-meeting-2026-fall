## 一、为什么要并行

本节落点：让你相信"单核已经到顶，剩下的速度只能从多核里拿"。

- 主频撞墙：2005 年前后单核主频冲到 3 GHz 上下就停了，功耗和散热扛不住；之后厂商改走加核。
- 你的机器、组里的服务器都是多核的（`lscpu` / `nproc` 自己看）。
- pivot 的活刚好能切开：从 500 个点里选 2 个枢轴，共 `C(500,2) = 124,750` 组，**组与组互不相干**——算第 1 组不需要第 2 组的结果。

能切开的活，才能分给多个核。

## 二、阿姆达尔定律：为什么到不了线性

本节落点：先接受"20 个核不会快 20 倍"，再想为什么。

假设程序里有比例 `f` 的部分无法并行：

```
加速比上限 = 1 / ( f + (1 - f) / N )        N = 线程数
```

| 串行比例 f | 4 线程 | 8 线程 | 20 线程 | 无限线程 |
|---|---|---|---|---|
| 5% | 3.48× | 5.93× | 10.26× | 20× |
| 10% | 3.08× | 4.71× | 6.90× | 10× |
| 50% | 1.60× | 1.78× | 1.90× | 2× |

- 串行部分是天花板：1% 的串行代码，能把 20 线程压到 16 倍左右。
- 顺序不能反：**先减少计算量（W04），再并行（W05）**。

## 三、线程、数据竞争、同步开销

本节落点：并行能变快，也会变错、变慢。

**进程 vs 线程**

| | 进程 | 线程 |
|---|---|---|
| 内存 | 各自独立一套 | 共享同一块 |
| 类比 | 各自独立的办公室 | 同一间屋子里几个人共用白板 |

**数据竞争**

- 一行 `sum += x` 其实是三步：读 sum → 加上 x → 写回 sum；
- 两个线程同时做，就可能都读到旧值，**丢掉一次加法**；
- 最麻烦的是**不是每次都错**——比崩溃更难查；
- 检测：编译加 `-fsanitize=thread`。

**同步三种手段**

| 手段 | 写法 | 适合 |
|---|---|---|
| 原子 | `#pragma omp atomic` | 单个变量加减 |
| 临界区 | `#pragma omp critical` | 一小段必须串行 |
| 归约 | `reduction(+:sum)` | 累加求和，最常用 |

同步有代价：锁竞争、线程起停、伪共享。

**正确性标准**：并行版必须和串行版 `diff` 一致。**先对，再快。**

## 四、OpenMP：三行改出并行版

本节落点：今天唯一必须带走的技能。

```c
#pragma omp parallel for reduction(+:sum)
for (int c = 0; c < ncombo; c++) { ... }
```

```bash
gcc -O2 -fopenmp pivot.c -o pivot_omp -lm
OMP_NUM_THREADS=8 ./pivot_omp uniformvector-2dim-5h.txt > run.log
```

- 编译**必须加 `-fopenmp`**，否则 `#pragma` 被当注释，默默忽略；
- 不写线程数时，由 `OMP_NUM_THREADS` 或机器核数决定。

**能不能并行，只看一条**：循环每一轮是否互不依赖。能就并行，不能就先改写。

**三个坑**：循环内的临时变量、循环内做 I/O、共享的临时数组。

## 五、现场演示

本节落点：看到"三行改完快了几倍"，也看到"为什么不是核数倍"。

- 用原始 `pivot.c` 起手，先跑单线程记时间；
- 加 `#pragma omp parallel for`，依次跑 1 / 2 / 4 / 8 线程；
- 每一档都 `diff` 一次，确认结果一致；
- 现场填这张表：

| 线程数 | 耗时 (ms) | 相对 1 线程 | 效率 |
|---|---|---|---|
| 1 | | 1.00× | 100% |
| 2 | | | |
| 4 | | | |
| 8 | | | |

参考数据（14 核 20 线程机器，同口径三次中位数）：

| 线程数 | 1 | 2 | 4 | 8 | 20 |
|---|---|---|---|---|---|
| 相对 1 线程 | 1.00× | 1.82× | 3.26× | 4.90× | 10.15× |
| 效率 | 100% | 91% | 82% | 61% | 51% |

**为什么到不了线性**：访存带宽被抢、同步与调度有开销、机器不是同速核（大小核混编）。
