### 新生

<!-- 统一流程，任务一致 -->

**统一规则**：
三步：**先问 AI → 动手去做 → 做成后把收获留档**——把过程留档，是把"AI 教我的"变成"我真正会的"的关键一步。
下周带上你的留档材料分享讲述你对于每个任务的思考、尝试、解决方法。

- [ ] **任务 1：连上服务器（必做）**
  - 你会拿到一张账号卡片（IP、端口、用户名、初始密码）；
  - 用 VS Code 的 Remote-SSH 插件连接到服务器；
  - 不会问的话，用这个模板起手：

    > 「我有一台 Linux 服务器，IP 是 xxx，端口是 xxx，系统是 Ubuntu。
    > 我想用 VS Code 远程连接它写代码，请一步步教我，我是纯新手。」

- [ ] **任务 2：无密码登录（必做）**
  - 连上服务器后，配置无密码登录（SSH 密钥）

- [ ] **任务 3：自由探索 + 收集命令（必做）**
  - 探索这台机器：什么系统？多少核 CPU、多大内存？现在在哪个目录？都有哪些文件？
  - 四类操作逐条亲手跑通：新建（文件/目录）、查看（内容/目录）、编辑（修改文件内容）、运行（跑一个程序）；
  - 至少 15 条命令，整理成《探索笔记》（文件名用英文，建议 `exploration-notes.md`），每条写三样：命令、作用、实际跑过的例子。

- [ ] **任务 4（选做挑战）**
  - 尝试把《探索笔记》传到 GitHub 仓库自己的文件夹（`W01/<你的缩写>/`）。
  - https://github.com/HZCU-HPC-Team
