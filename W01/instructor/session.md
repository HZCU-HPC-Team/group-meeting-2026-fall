- 区分「被拦截」（DNS 污染 / 连接阻断 / IP 封锁）与「跨境拥塞」两类成因；科学上网 = 中转 + 加密通道。

#### 议题二

- 组织 HZCU-HPC-Team 与组会仓库结构；注册账号后把用户名发群里，由讲师发组织邀请。

#### 议题三

- 每人领到账号卡片（IP / 端口 9446 / 用户名 / 初始密码）；演示 VS Code Remote-SSH 连接，具体步骤留给学生问 AI 学会。

#### 议题四

- 统一规则：先问 AI → 动手去做 → 做成后留档；四项任务：连服务器、无密码登录、探索 + ≥15 条命令、选做（传笔记到仓库）；下次组会带留档材料分享。

#### 议题五

- 设置 AI 部署项目：以 8×A800（80GB ×8，NVLink）为目标硬件做前置理论调研；交付标准三项：模型与版本、显存与 KV 核算、部署方案与同规格成功案例；开启下一轮调研。
