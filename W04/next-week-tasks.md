## 本周要做什么

### 新生

**规则不变**：先问 AI → 动手去做 → 做成后把收获留档。

**本次主题**：优化 pivot——版本管理、出火焰图、减少计算量。

**本周作业：**

- [ ] **1. 版本管理**
  - 在 baseline 上打标签：`git tag v0-baseline`；
  - 以后每改一版就是一个 commit，记住每一版花了多少时间、对应哪个 commit。

- [ ] **2. 出一张火焰图**
  - 用 perf：`perf record -g ./pivot_O0 <输入文件>`，再用 FlameGraph 脚本生成 `flame.svg`；
  - 或者用本地已装的 VTune：激活环境后做 hotspots 分析，GUI 截图或 `-report` 输出；
  - 图上写清输入规模、采集命令、坐标轴和单位——比赛报告要用。

- [ ] **3. 把热点抽象成式子**
  - 算清楚：多少组枢轴、每组多少个点对、哪些计算在重复；
  - 写成 `T ≈ C(n,k) × n² × 常数`，标出重复的部分。

- [ ] **4. 想几个减少计算量的 idea**
  - 在你能理解的范围内多想几个，写清每个改哪里、减少哪一项；
  - 可以问 AI 有哪些方法；
  - 想不出来，或者超出了自己目前的理解范围，不必强求，把已经做到的记录好就行。

- [ ] **5. 测一遍并记录**
  - 选一个想法实现，只改一处，改完保证 `diff` 一致；
  - 重新编译，至少跑 3 次取中位数；
  - 在 `iterations.md` 里记：版本、commit、改了什么、耗时、相对上一版、`diff` 结果。
  - 没变快也要记，失败就 `git revert` 回去。

- [ ] **6. 下次组会分享（3 分钟）**
  - 火焰图 + 式子 + 你的 idea + 优化前后的时间对比。

**提交**：截止下次组会前，PR 到 `W04/<你的缩写>/`。
