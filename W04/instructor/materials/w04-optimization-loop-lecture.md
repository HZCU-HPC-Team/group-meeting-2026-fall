## 一、版本管理（先做，后面每一步都靠它）

**三条硬规矩**

- 基线打标签：`git tag v0-baseline`
- 一次改动一个 commit，源码和记录一起提交
- 失败的尝试用 `git revert` 回退，不要手动改回去

**提交信息带数据**

```
opt: <改了什么> | <编译选项> | 132.4s -> 41.7s | diff ok
```

**每一版必须回答两个问题**

- 这一版**花了多少时间**？（同一输入、同一机器、至少 3 次取中位数）
- 这一版的**源代码是什么**？（tag 或 commit hash）

**迭代表 `iterations.md`**

| 版本        | commit / tag | 改了什么 | 编译选项 | 耗时（中位数） | 相对上一版 | diff | 结论        |
| ----------- | ------------ | -------- | -------- | -------------- | ---------- | ---- | ----------- |
| v0-baseline |              | 原始代码 | -O0      |                | —         | ok   | 基准        |
| v1          |              |          |          |                |            |      | 保留 / 回退 |

规则：看这张表就能回到那一版、复现那次测量。缺一项就算没记录。

输入数据、`result.txt`、`run.log` 不进仓库。

## 二、profiling：perf 火焰图，或试 VTune

**路线 A：perf + 火焰图（默认）**

```bash
perf record -g ./pivot_O0 uniformvector-2dim-5h.txt
perf script | ./FlameGraph/stackcollapse-perf.pl | ./FlameGraph/flamegraph.pl > flame.svg
```

- 火焰图横轴越宽越耗时，纵向是调用栈，不是时间轴；
- 栈缺失就加 `--call-graph dwarf` 重采，不要交一张全是 `unknown` 的图；
- 没有 FlameGraph 脚本的，从 `brendangregg/FlameGraph` 拉一份，缺 `perl` 找讲师。

**路线 B：VTune（本地已安装，想试的用）**

```bash
source /opt/intel/oneapi/setvars.sh        # 以机器上的实际安装路径为准
vtune --version

vtune -collect hotspots -result-dir vtune-r1 -- ./pivot_O0 uniformvector-2dim-5h.txt
vtune -report summary -result-dir vtune-r1
```

- 有图形界面的机器直接 `vtune-gui` 打开结果，截图上传；
- 没有图形界面就用 `-report` 输出，图至少要有 hotspots 汇总。

**图的硬要求**

- 一张能直接放进比赛报告的图：有标题、坐标轴与单位、输入规模、采集命令；
- 用 perf 交火焰图，用 VTune 交 hotspots 图；用其他工具（gprof、callgrind）也必须出图；
- 图要能回答"时间花在哪"，不是装饰。

## 三、把热点抽象成能想明白的形式

以 `SumDistance` 为例，先别急着改代码：

1. **数操作**：多少组枢轴（C(n,k)）？每组要重建多少个点、算多少对点？
2. **找重复**：哪些距离被反复算？哪些和在反复求？
3. **写成式子**：`T ≈ C(n,k) × n² × 每对点的常数`

换成这个形式之后，"减少计算量"才有落点：减少组数、减少每对的运算，或者把重复的部分只算一次。

**可以问 AI**

- 这个函数在算什么？
- 哪些计算是重复的？
- 有哪些减少计算量的方法？各需要改哪里？

AI 给的是候选，不是结论。

## 四、自己想 idea：减少计算量

几个方向，按自己的数据选：

- **不重复算**：缓存距离或中间和，避免同一对点算两次；
- **少算**：利用对称性、剪枝、提前终止；
- **换循环顺序**：减少重复访存；
- **分清两类优化**：删日志是省 I/O，不是减少计算量。可以写，但要标注清楚。

规矩：一次只改一处；改完重新编译、`diff`、至少测 3 次、填表。
