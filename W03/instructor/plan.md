## 材料归档

材料放在 `instructor/materials/`，命名规则：

| 类型 | 命名格式 | 示例 |
|---|---|---|
| 幻灯片 | `w01-<topic>-slides.pptx` | `w01-vscode-intro-slides.pptx` |
| 讲义文档 | `w01-<topic>-notes.md` | `w01-linux-basics-notes.md` |
| 实机演示 | `w01-<topic>-demo/` | `w01-ssh-demo/` |
| 参考资料 | `w01-<topic>-ref.pdf` | `w01-ide-tools-ref.pdf` |

- 文件夹和文件名一律英文，不出现中文
- 同一主题跨周复用时，在文件名中保留主要周次
- 大文件（>50 MB）走 GitHub Releases，此处只放链接
