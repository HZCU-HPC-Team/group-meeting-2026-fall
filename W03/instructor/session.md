### 本次流程顺序

### 议题

1. 回顾 W02 作业：这周做了什么、学到了什么
2. 赛题 pivot（2022 IPCC）介绍与源码包结构
3. 跑通程序的完整链路（标准动作）
4. perf 三件套：`stat` / `record` / `report`
5. W03 作业布置

### 讨论要点

#### 议题一

- 收 W02 作业分享：从 `teach` 学到的"跑通程序"要经过哪些步骤。
- 点出：知道 ≠ 做到，今天把所有步骤按同一套规范走一遍。

#### 议题二

- 赛题：从 n 个 dim 维点中选 k 个枢轴，重表示为到各枢轴的距离，计算点对切比雪夫距离之和，输出最大的 M 组与最小的 M 组。
- 源码包：`pivot.c`、输入 `uniformvector-2dim-5h.txt`、基准输出 `refer-2dim-5h.txt`。
- 复杂度 O(C(n,k)·n²)：baseline 单次需数分钟，并打印大量迭代日志（W04 处理）。

#### 议题三

- 标准动作六步：环境检查 → 编译 → 运行 → 正确性校验 → 测量 → 记录。
- 编译对比 `-O0` / `-O2`；校验用 `diff`，先对再快；测量用 `time`，多跑取平均，算加速比。
- 装东西之前先问三件事：已经有了吗（`which` / `dpkg -l`）？有没有同类工具？有没有更新版本？

#### 议题四

- `perf stat` 看 cycles / instructions / cache-misses / branch-misses，判断计算密集还是访存密集。
- `perf record` + `perf report` 找热点函数（本程序大概率在 `SumDistance`）。
- 提示：perf 报权限不足时找讲师处理。

#### 议题五

- 布置 W03 作业：跑通赛题 → 说清最小单位 → 编译优化实验 → perf（本周重点）→ 说明文件 + 分享准备。
- 下次组会重点分享 perf：学到什么、数据怎么采集、数据有什么用。

### 结论

- 编译、运行、校验、测量的完整链路讲完，perf 三件套演示完成。
